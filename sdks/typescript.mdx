This page documents `@senderkit/sdk`, the official TypeScript client — installation,
client construction, and the send and template operations it exposes. It is
ESM + CJS, zero-dependency, and runs on Node.js 18+ and edge runtimes. Method
signatures will be filled in from the SDK source.

<CodeGroup>
  ```bash npm
  npm install @senderkit/sdk
  ```

  ```bash pnpm
  pnpm add @senderkit/sdk
  ```

  ```bash bun
  bun add @senderkit/sdk
  ```
</CodeGroup>
