This page documents the fastest path to connecting an AI assistant to SenderKit
over MCP — pointing a client at the server and authenticating with an API key. The
steps below are scaffolding to be expanded with exact configuration.

<Steps>
  <Step title="Get an API key">
    Create a key in the dashboard. See [Authentication](/authentication).
  </Step>
  <Step title="Point your client at the server">
    Use the hosted server at `/mcp` or run the CLI-bundled server. Client-specific
    setup is covered in [Installation](/mcp/installation).
  </Step>
  <Step title="Send from your assistant">
    Ask the assistant to send a message or list templates using the MCP
    [tools](/mcp/tools).
  </Step>
</Steps>
