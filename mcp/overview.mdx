This page introduces the SenderKit MCP server, which lets AI assistants send
messages and inspect templates and delivery history over the Model Context
Protocol. The server is available two ways — hosted by SenderKit at `/mcp` and
bundled in `@senderkit/cli` — both authenticated with the same API keys. Details to
be expanded from the MCP source.
