This page documents installing and authenticating `@senderkit/cli`, which exposes
the same operations as a `senderkit` command and bundles an MCP server. Exact
configuration and auth flags will be filled in from the CLI source.

<CodeGroup>
  ```bash npm
  npm install -g @senderkit/cli
  ```

  ```bash pnpm
  pnpm add -g @senderkit/cli
  ```

  ```bash bun
  bun add -g @senderkit/cli
  ```
</CodeGroup>
